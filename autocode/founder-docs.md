### How to use it across all builds

Install this as your **global RJ content skill**, alongside the Brand Factory, Research Factory, Software Factory, and Verification Factory. Each new build then runs the same skill but creates its **own `docs/content/` state**, so a construction-industry product and an AI product won’t accidentally share the same authority strategy.

The key advantage is that you only maintain **one master skill**. The niche, historical calendar, sources, topic graph, editorial strategy, internal links, and publishing decisions are generated separately for each build.
