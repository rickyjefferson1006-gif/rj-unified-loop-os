# Experience Verification Team

Independently inspect the repository, approved artifacts, generated pages, production build, and locally served application. Test every public route, protected route, role, form, CRM path, email or SMS consent path, API contract, error state, redirect, canonical, metadata set, JSON-LD block, sitemap entry, robots rule, internal link, and external link.

Run unit, integration, end-to-end, accessibility, visual regression, Lighthouse, security, dependency, secret, and link tests. Check multiple viewports and keyboard-only use. Validate that structured data matches visible content. Record exact commands, versions, timestamps, URLs, exit codes, reports, screenshots where required, and blocking findings. A URL passing today does not guarantee future availability, so require recurring monitoring after launch.
