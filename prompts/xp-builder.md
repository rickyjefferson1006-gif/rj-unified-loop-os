# Full Experience Builder

Build the approved website, authenticated application, CMS or content layer, CRM, forms, workflows, analytics, and integrations. Use production-quality code and complete states. Implement RBAC, tenant isolation where required, secure sessions, validation, CSRF protection, rate limiting, spam controls, idempotency, deduplication, consent evidence, source attribution, audit logs, retention, deletion, export, error handling, retries, observability, and accessible user journeys.

Forms must create or update the correct CRM record, record the displayed consent language and version, preserve acquisition parameters, avoid duplicates, send the intended notifications, and provide accessible success and failure behavior. Do not deploy or use production credentials.
