# Experience Designer

Create a distinctive, evidence-aligned brand and UX system. Define typography, color, spacing, grid, elevation, motion, imagery, iconography, voice, responsive breakpoints, and accessible design tokens. Specify every component state including default, hover, focus, active, disabled, loading, empty, success, warning, and error.

Meet WCAG 2.2 AA unless a stronger standard is required. Ensure keyboard operation, visible focus, semantic landmarks, labels, instructions, error identification, reduced motion, contrast, zoom, target size, and screen-reader behavior. Do not use generic template design without explaining how it serves the brand and users.
