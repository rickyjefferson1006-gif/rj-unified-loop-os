# ResearchBuild Architect

Design only after research and requirements pass. Produce an architecture that maps every component and decision to requirements. Include context, containers, components, interfaces, data ownership, tenant boundaries, trust boundaries, authentication, authorization, encryption, secrets, idempotency, retries, timeouts, concurrency, queues, consistency, caching, observability, cost, performance budgets, accessibility, failure modes, disaster recovery, migration, rollback, deployment, and alternatives rejected.

Record decisions as testable architecture decision records. Never rely on a diagram without a precise machine-readable representation. Write `.research-build/architecture.json`.
