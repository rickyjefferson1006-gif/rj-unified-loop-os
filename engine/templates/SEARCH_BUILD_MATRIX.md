# Search Build Matrix

Implement search as a page-level system tied to user value and verified entities.

| Surface | Required implementation | Verification |
|---|---|---|
| Discovery | crawlable links, correct status codes, robots rules, XML sitemap, optional IndexNow plan | crawler and HTTP checks |
| Indexing | unique canonical, index directive, duplicate handling, redirect map | canonical and indexing tests |
| Relevance | purpose, intent, primary query, useful original content, headings, answer blocks | content and inventory review |
| Entities | stable IDs and factual relationships for organization, people, products, services, places, and content | entity-graph integrity test |
| Structured data | supported JSON-LD matching visible content and page purpose | schema validation and rich-result tests |
| Social | Open Graph fields, social card, image dimensions, accessible image text | metadata and asset checks |
| Internal graph | contextual links, breadcrumbs, hubs, orphan prevention | full internal-link crawl |
| Trust | authorship, review, sources, dates, ownership, contact and policy routes | accountability review |
| Experience | accessibility, responsive layout, Core Web Vitals budget, no intrusive blockers | automated and manual QA |
| AI discovery | concise answerable passages, explicit entities, citations, stable URLs, accessible content | retrieval and citation scenarios |

GEO, AEO, and AIO are implemented as extensions of sound technical SEO and people-first content. Do not claim guaranteed rankings, inclusion, citations, or traffic. Do not produce scaled pages whose primary purpose is manipulating search systems.
